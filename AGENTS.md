# Regras de Resposta

- **Zero explicações não solicitadas:** Não explique o que você alterou, não resuma passos concluídos e não liste os arquivos modificados a menos que eu pergunte explicitamente.
- **Edição silenciosa:** Use as ferramentas de edição diretamente nos arquivos. Não repita blocos de código no chat após aplicar a alteração.
- **Formato da resposta:** Quando terminar uma tarefa, responda apenas: "Concluído." ou reporte estritamente erros/bloqueios se algo der errado.
- **Mantenha os diffs mínimos:** Edite estritamente as linhas necessárias, sem refatorar ou reformatar código ao redor.
